# Detroit, first-read corrections (human-voice pass, step 2)

The five corrections from the first, figure-first read of the fact-check (rows 4, 5, 6, 21 and 23). A one-off script applied them first on 2026-09-10. This file records them in the change-set format, so the full correction set replays on any copy of the page with `reference/voice_apply.py`, in the order 0, 1, 1b. Edit IDs match the review page.

## R4 hero: municipality, not city
<<<
Every eligible Michigan retail license earned its city a $54,017.10 excise check this year.
===
Every eligible Michigan retail license earned its municipality a $54,017.10 excise check this year.
>>>

<<<

Statewide, $93.8 million went out to municipalities and counties, for 860 licenses in 234 municipalities.
>>>
