What happened

Four things had to be true before Google would clear it

The manual action was "thin content with little or no added value," applied site wide. Here is the sequence that closed it out.

  1. Root cause identifiedFixed

    The 21+ age gate was redirecting Googlebot to a single interstitial page, so every URL on the domain resolved to the same content. Google read the whole site as thin and duplicative.

  2. Redirect removed and verifiedVerified

    The site now returns a 200 to Googlebot and to cookie-less browsers, with real page content served on the first request.

  3. Contributing factors clearedDone

    584 WordPress tag archive pages against roughly 185 posts, plus a run of near-daily formulaic articles, were adding weight to the thin-content signal. Tag archives were noindexed and the publishing pattern was stopped.

  4. Reconsideration request filed and approvedApproved

    A one-shot submission, reviewed before filing. Google approved it on September 26 and confirmed the manual action has been removed.
